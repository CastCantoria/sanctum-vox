# 🕊️ Sanctum Vox – Sanctuaire numérique du C.A.S.T.

**Foi, art, et harmonie**  
Site web officiel du **Chœur Artistique & Spirituel de Tanà (C.A.S.T.)**

---

## 🎯 Présentation

Bienvenue dans le sanctuaire numérique du **C.A.S.T.**, une chorale artistique et spirituelle basée à Antananarivo. Ce projet vise à :

- 🎶 Partager nos chants et compositions
- 🎥 Diffuser nos vidéos et messages spirituels
- 📸 Exposer nos galeries d’images
- 📜 Offrir un espace de méditation, de prière et d’inspiration

Ce dépôt contient le code source du site web, les scripts d’automatisation, les ressources multimédia et les API nécessaires à son bon fonctionnement.
